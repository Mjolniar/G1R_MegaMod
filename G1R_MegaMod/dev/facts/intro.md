# Facts: module intro

`G1R/Config/DefaultGame.ini` (read from `G1R-Windows.pak` on 2026-10-06: pak version 11, index not encrypted, the
file compressed with Oodle), the game's scripts (`as-src`), the property layout of build `Build83_CL174209`
(`usmap.py`), the native function table of the game's program (`re-tools/params.py`), the loose files of
`G1R/Content/Movies/`. Nothing of this module has run in the game yet.
