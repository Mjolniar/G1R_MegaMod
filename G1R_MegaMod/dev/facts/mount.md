# Facts: module mount

What has run in the game: the section "Seen in the game" at the end. Sources: the game's scripts (`as-src`), the game
executable (`re/params.py`, string addresses of build `Build83_CL174209`), the property layout (`usmap.py`), the
script bindings (`re/binds_strings.txt`), the megamod's own sessions.

Why the module exists: the player, 2026-10-05: "Sometimes my scavenger won't come to me when called, seems to be a new
problem, fixed on restart." Nothing in this mod acts on the mount or on riding: the only creature call of the mod is
`RemoveFromWorld` on *dead* states of the species in the respawn data (the mount is not in it, and has 1e39 health),
and the hero's tags are only touched by regen's `State.OutMana`. So the module looks at what the game says and puts
the game's own states right.
