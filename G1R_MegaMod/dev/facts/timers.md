How long what is on the hero still lasts. Sources: the game's scripts (`as-src`), the property layout of build
`Build83_CL174209` (`usmap.py`), the native function table of the game's program (`re-tools/params.py`), the research
note `mega/research/q3/spell-timers.md`. Nothing of this module has run in the game yet.
