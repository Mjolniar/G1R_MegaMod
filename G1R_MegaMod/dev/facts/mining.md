## Session log

With the diagnostics on, the module writes a breadcrumb before each step into the game it takes for the first
time in a run (each once): the call of `GetWorldDefinition`, the first `HasGameplayTag`, the first write of a
mining number, the first `HasItemMain`, the first `Multicast_AddNewItem`, the first write of a slot count, the
first `GetContainerDataModule`. A session log that ends with one of these lines names the step the game ended in.
The first swing that gave ore is recorded as one event line: what the swing gave, what the numbers in force and
the game's own numbers said, and the vein's ore when it was found, when the swing ended and after it.
