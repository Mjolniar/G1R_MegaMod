# Facts: module melee

Sources: the game executable (addresses of build Build83_CL174209; read with the research tools `redis_.py` /
`params.py`), the game's scripts (`as-src`), the property layout (usmap), the native binds (`binds_strings.txt`),
the upstream UE4SS source, and what two other mods did in the game on this installation (UE4SS.log of 2026-10-01).
In the game the module has only run idle (megamod 0.2.1, session of 2026-10-04 21:19 - 23:39: all three settings as
the game has them, status "nothing to change: the game is not looked at", 0 looks, 0 errors): nothing of what it
changes has run in the game.
