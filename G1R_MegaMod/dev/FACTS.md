# Facts the code relies on

Read this before changing anything. Nothing in this mod can be tried in the game while it is written, so every
line of code rests on an assumption about the game or about UE4SS. This file lists them with how well each is known.
Do not upgrade a status without evidence of that kind.

Status words:

- **IN-GAME** - seen working in a real game session (a line in UE4SS.log or in the mod's diagnostics says so).
- **DISASM** - read from the installed UE4SS.dll or the game executable.
- **SOURCE** - from the decompiled game scripts, the property layout (usmap) or the upstream UE4SS source.
- **OFFLINE** - only exercised by the offline tests against a model of the game. The model can be wrong.
- **UNKNOWN** - not known.

The last part ("Diagnostics notes") is read by `dev/tools/diagread.py`: after a play session it compares what the
modules saw with what is expected here. That is how OFFLINE and UNKNOWN lines get settled.
